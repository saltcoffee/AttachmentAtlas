# Code of conduct

Attachment Atlas welcomes contributors of all backgrounds and experience levels. This policy applies to project issues, pull requests, discussions, reviews, and other project-managed spaces.

## Expected behavior

- Be respectful, clear, and constructive.
- Discuss ideas and evidence without attacking people.
- Make room for different languages, perspectives, and accessibility needs.
- Respect private vault content, personal information, and boundaries.
- Accept reasonable moderation and correct mistakes when identified.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized conduct, personal attacks, publishing private information without consent, and repeated disruptive behavior are not acceptable.

## Reporting and moderation

Use a private repository reporting channel where one exists. If no private contact is published, request one without posting private details. Repository owners must establish a verified private contact before the first public plugin release.

Maintainers may edit or remove harmful content, close or lock discussions, limit participation, or block repeat offenders. Decisions should be proportionate to the behavior and prioritize the people affected. Reports should be handled discreetly; confidentiality cannot be guaranteed when a platform or legal process requires disclosure.
